# Handoff: редизайн приложения «Аудиокниги»

## Overview
Полный редизайн офлайн-плеера аудиокниг (Expo / React Native, FSD): шесть экранов — онбординг, библиотека, карточка книги, плеер, поиск, настройки. Визуальная система — **Modernist**: гротеск, светлый ground, единственный красный акцент, плоские поверхности, мягкие скругления 8–22px и лёгкие тени. Обложки — детерминированные градиенты по id книги (как сейчас в `shared/lib/coverGradient.ts`), это единственный цветной элемент интерфейса.

## About the Design Files
Файлы в этом бандле — **дизайн-референсы, сделанные в HTML**. Это прототипы, показывающие внешний вид и поведение, а не продакшн-код для копирования. Задача — **воспроизвести эти макеты в существующем окружении приложения**: React Native + Expo Router, голый `StyleSheet`, токены из `src/shared/ui/theme.ts` и `src/shared/ui/playerTheme.ts`, иконки `@expo/vector-icons`. Никаких новых UI-библиотек не требуется.

## Fidelity
**High-fidelity.** Цвета, типографика, размеры и отступы финальные — воспроизводить точно, адаптируя только под нативные примитивы (`Pressable`, `FlatList`, `SafeAreaView`) и hit-таргеты ≥44px.

## Навигация
Таб-бар (52px, 1px `divider` сверху, фон `bg`): **Библиотека · Поиск · Настройки**, подписи 9.5/800 uppercase 0.10em, флеш-лефт с паддингом 12; активный таб помечен полосой 3px `accent` **сверху** ячейки (не иконкой). Показывается на библиотеке, поиске и настройках; на карточке книги и в плеере скрыт.
Мини-плеер (54px, фон `#262322`) сидит **над** таб-баром: обложка 38×38, название 11.5/800 uppercase, «Тёмный город · 12:04» 9.5/400, круглая play-кнопка 34px fill accent. Тап по мини-плееру → плеер; тап по кнопке — toggle, без навигации (`stopPropagation`).

## Interactions & Behavior
- Переходы: онбординг → библиотека → карточка книги → плеер; из библиотеки: поиск, настройки; из плеера `✕` → карточка книги.
- Книга с одной главой из библиотеки открывается сразу в плеере (текущее поведение сохраняется).
- Play/pause: мгновенная смена иконки, эквалайзер на обложке появляется/исчезает.
- Seek: тап или drag по полосе, позиция округляется до секунды, сохраняется per-file.
- Скорость: тап по кнопке циклит `SPEED_PRESETS`, подпись обновляется (десятичная запятая, `1,25×`).
- Pressed-состояния: акцентные заливки → `accent600`; outline и ghost → тинт `rgba(38,35,34,0.06)` (на тёмном `rgba(251,250,249,0.12)`); `opacity` не использовать как единственный сигнал.
- Все тап-цели ≥44px по высоте (в макете часть строк визуально 38–40 — добирать `hitSlop`).
- Анимации: только эквалайзер (0.9 с, ease-in-out, infinite) и стандартные переходы навигации. Шит таймера — slide-up 220 мс.

## State Management
Новых сущностей не требуется — используется текущий стор:
- `playback`: `bookId`, `chapterIndex`, `positionSec`, `status`, `rate`, `sleepUntil` — питает плеер, мини-плеер, активную строку в списке файлов.
- `books`: `progress.chapterIndex`, `progress.updatedAt`, `chapterPositions` — прогресс на обложках, «Продолжить», статусы «Прослушано».
- `settings`: `defaultRate`, `skipSeconds`, `themePref`, `resumeOnOpen`, `defaultSleep` — экран настроек; **добавить** `onboardingSeen: boolean`.
- Экран поиска: локальный `query` + селектор по книгам/главам; результаты «файлы на устройстве» — из `features/import-book`.
